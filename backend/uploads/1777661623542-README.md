# DTC Automated Bus Scheduling & Route Management System

## Project Structure

```
dtc-bus-system/
├── frontend/
│   └── index.html              ← Angular-style SPA (run directly in browser)
├── backend/
│   ├── pom.xml                 ← Maven dependencies (Spring Boot 3.2, Java 17)
│   └── src/main/java/com/dtc/
│       ├── DtcBusSystemApplication.java
│       ├── model/              ← JPA Entities
│       │   ├── Bus.java
│       │   ├── Route.java
│       │   ├── RouteStop.java
│       │   └── Schedule.java
│       ├── controller/         ← REST Controllers
│       │   ├── BusController.java
│       │   ├── RouteController.java
│       │   └── ScheduleController.java
│       ├── service/            ← Business Logic
│       │   ├── BusService.java
│       │   ├── RouteService.java
│       │   └── ScheduleService.java
│       └── repository/         ← JPA Repositories
│           └── Repositories.java
└── database/
    └── schema.sql              ← MySQL DDL + seed data
```

## System Modules (from your notes)

| Module         | Features                                      |
|----------------|-----------------------------------------------|
| Admin Module   | Bus add/update/delete, Route manage, Schedules |
| Bus Module     | Bus details (Bus No., type, capacity, driver) |
| Route Module   | Source, destination, stops                    |
| Schedule Module| Timing and bus assignment                     |

## REST API Endpoints

### Buses (`/api/buses`)
| Method | Endpoint       | Description          |
|--------|----------------|----------------------|
| GET    | /api/buses     | Get all buses        |
| GET    | /api/buses/{id}| Get bus by ID        |
| POST   | /api/buses     | Add new bus          |
| PUT    | /api/buses/{id}| Update bus           |
| DELETE | /api/buses/{id}| Delete bus           |

### Routes (`/api/routes`)
| Method | Endpoint              | Description             |
|--------|-----------------------|-------------------------|
| GET    | /api/routes           | Get all routes          |
| GET    | /api/routes/{id}      | Get route by ID         |
| POST   | /api/routes           | Add new route           |
| PUT    | /api/routes/{id}      | Update route            |
| DELETE | /api/routes/{id}      | Delete route            |
| GET    | /api/routes/search?source=&destination= | Search routes |

### Schedules (`/api/schedules`)
| Method | Endpoint                       | Description               |
|--------|--------------------------------|---------------------------|
| GET    | /api/schedules                 | Get all schedules         |
| GET    | /api/schedules/route/{routeId} | Schedules by route        |
| GET    | /api/schedules/bus/{busId}     | Schedules by bus          |
| POST   | /api/schedules                 | Create schedule           |
| PUT    | /api/schedules/{id}            | Update schedule           |
| DELETE | /api/schedules/{id}            | Delete schedule           |

## Setup Instructions

### 1. Database
```sql
-- Run the schema file
mysql -u root -p < database/schema.sql
```

### 2. Backend (Spring Boot)
```bash
# Update application.properties with your MySQL password
# Then run:
cd backend
mvn spring-boot:run
# API runs on http://localhost:8080
```

### 3. Frontend
```bash
# Open directly in browser — no build step needed
open frontend/index.html

# Or serve with any static server:
npx serve frontend/
```

## Tech Stack
- **Frontend**: Angular-style SPA (HTML5 + Vanilla JS)
- **Backend**: Java 17 + Spring Boot 3.2 + Spring Data JPA
- **Database**: MySQL 8.x
- **Security**: Spring Security + JWT (configured in pom.xml)
- **Build**: Maven
